# Samples

These files exercise the constructs the grammar highlights: definitions,
macros and quasiquote, `{:hint}` contracts, PEGs, error handling, and
event channels.

They were written for this grammar and may be redistributed under the MIT
license that covers this directory. They are not copied from third-party
projects.

Every sample compiles with:

```sh
bender -k samples/actors.ben
```
